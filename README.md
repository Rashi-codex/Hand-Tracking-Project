# ✋ Real-Time Hand Tracking System

A real-time hand tracking system built using **Python, OpenCV, and MediaPipe** that detects hand landmarks and tracks finger movements through a webcam.

## 🚀 Features
- Real-time hand detection using webcam
- Hand landmark tracking
- Finger position detection
- Live FPS display
- Modular code structure for better understanding

## 🛠️ Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## 📂 Project Structure

```bash
Hand-Tracking-System/
│── hand.py
│── hand_module.py
│── check.py
│── myhandtackgame.py
│── requirements.txt
│── README.md
```

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Rashi-codex/Hand-Tracking-System.git
```

2. Navigate to project folder:

```bash
cd Hand-Tracking-System
```

3. Install required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

Run the main file:

```bash
python hand_tracking.py
```

Press **Q** to exit the webcam window.

## 📸 Output
The system detects hand landmarks in real time and tracks finger positions using your webcam.
